Program

USB export (Operateur 2000)

Writes the program in the machine's own format: N.PLI plus an updated FPROG.DAT. Back up the stick first, and test with a simple part. Uses Program no., Job reference (13 chars), Thickness, Punch and Die from the Program panel. Program no. must be 1-98.

Y is not calculated here. Leave it empty to write 0 and let the control calculate it from the angle (retype the angle on each step if it does not). Or type the value the control shows.

No bend
Select a bend in the sequence to see the backgauge fingers.

Up folds the flange toward you as drawn; Down folds it away, so the part is turned over (FLIP). Distances are flat-pattern distances from the bend line to the edge, in mm.

Z1 moves the left finger to the left of the centre, Z2 the right finger to the right (100 mm wide, Z = finger centre, machine 2500 mm). A finger may go past the centre (negative Z); Z1 + Z2 must stay at least 120. R1/R2 raise each finger's support ledge above the die top. Fingers are placed on the gauged edge automatically when you add a bend; typing in Z1/Z2 stops that, and Auto fingers brings it back. The flat pattern is folded bend by bend (earlier bends are included) and assumes every bend line runs across the whole part. Punch and die are approximate shapes (punch tip 88°, die with V8 and V12 slots, bending in the V8 at the back). In the top view you can drag the Z1/Z2 fingers. Click a row in the bend table to simulate that step.
